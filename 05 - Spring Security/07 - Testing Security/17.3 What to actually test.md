## ✅ Checklist

- [ ] 17.3.2 Protected endpoints return 401 without auth
- [ ] 17.3.3 Protected endpoints return 403 for wrong role/authority
- [ ] 17.3.4 Protected endpoints return 200 for correct role/authority
- [ ] 17.3.5 Ownership checks: user A cannot access user B's resource (the IDOR test — arguably the most valuable test in the whole suite)
- [ ] 17.3.6 CSRF: state-changing request without token is rejected; with token succeeds

- [ ] 17.3.9 Login failure returns a generic error, not "user not found" vs "wrong password"
- [ ] 17.3.10 Logout invalidates the session / token
- [ ] 17.3.11 Expired JWT is rejected with 401
- [ ] 17.3.12 Tampered JWT signature is rejected with 401
- [ ] 17.3.13 JWT with wrong `aud`/`iss` is rejected
- [ ] 17.3.14 Method security: `@PreAuthorize` denies at the service layer even if a controller check is bypassed
- [ ] 17.3.15 Rate limiting / lockout triggers after threshold attempts
- [ ] 17.3.16 Security headers are present on responses (assert `X-Frame-Options`, `Content-Security-Policy`, etc.)
