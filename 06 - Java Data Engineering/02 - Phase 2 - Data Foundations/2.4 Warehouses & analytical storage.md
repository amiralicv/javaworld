## ✅ Checklist

You cannot use Snowflake, BigQuery or Redshift from Iran. **Good news: the open-source analytical stack is stronger than ever, and you learn more by running it yourself.** See [[06 - Java Data Engineering/06 - Iran Playbook|Iran Playbook]].

- [ ] Row storage vs **columnar storage** — why analytics wants columns
- [ ] Compression, encoding, predicate pushdown
- [ ] **ClickHouse** — self-hosted, extremely fast OLAP. This is your warehouse. Learn `MergeTree`, partitions, primary keys, materialized views.
- [ ] **DuckDB** — an analytical database in a single file. Perfect for local development and testing. Use it constantly.
- [ ] **Parquet** — the file format of the data world. Row groups, column chunks, statistics, why it beats CSV by 10x.
- [ ] Avro and ORC — know what they are and where they show up
- [ ] Partitioning and file layout on object storage
- [ ] **MinIO** — self-hosted S3-compatible object storage. This is your "data lake" and it runs on one machine.

> **You are done when…** you can load 50+ million rows into ClickHouse from Parquet on MinIO and query it in under a second, and explain *why* it is fast.
