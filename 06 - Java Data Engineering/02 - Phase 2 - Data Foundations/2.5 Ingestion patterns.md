## ✅ Checklist

- [ ] Batch vs streaming — and the honest truth that **most business problems are fine with batch**
- [ ] Full load vs incremental load
- [ ] Watermarks / high-water marks for incremental extraction
- [ ] **Change Data Capture (CDC)** — reading the database log instead of polling. Tool: **Debezium** (JVM-based — your Java pays off again)
- [ ] API ingestion — pagination, rate limits, retries, idempotency keys
- [ ] File ingestion — landing zones, schema drift, corrupt files, the file that arrives twice
- [ ] Schema evolution — what happens when a source adds/removes/renames a column at 2 AM

> **You are done when…** you have built an incremental loader that can be re-run any number of times and always produces the same correct result.
