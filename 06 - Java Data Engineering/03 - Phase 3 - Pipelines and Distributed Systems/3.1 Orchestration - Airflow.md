## ✅ Checklist

Every data team has an orchestrator. Airflow is still the most common one to be paid for.

- [ ] DAG concepts — tasks, dependencies, operators, sensors
- [ ] Scheduling, **execution date vs run date** (this confuses everyone once; understand it properly)
- [ ] **Idempotency and backfills** — re-running last month must not corrupt anything
- [ ] Retries, timeouts, SLAs, alerting on failure
- [ ] XComs, and why passing large data through them is a mistake
- [ ] TaskFlow API, dynamic task mapping
- [ ] Connections and secrets handling
- [ ] Executors — Local vs Celery vs Kubernetes, and what each costs you
- [ ] Testing DAGs (yes, this is possible, and almost nobody does it — do it)

**Also know they exist:** Dagster and Prefect (more modern, asset-based thinking). Learn Airflow first because that is where the jobs are; read the Dagster docs to steal the ideas.

> **You are done when…** you can backfill 6 months of history for a broken pipeline and be *confident* the result is correct.
