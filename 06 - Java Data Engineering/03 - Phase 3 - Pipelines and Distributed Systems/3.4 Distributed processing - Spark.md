## ✅ Checklist

- [ ] The mental model — driver, executors, cluster manager, partitions
- [ ] RDD vs DataFrame vs Dataset (use DataFrames; know why the others exist)
- [ ] Transformations vs actions, **lazy evaluation**
- [ ] **Shuffles** — the source of ~90% of Spark performance problems
- [ ] Joins — broadcast vs sort-merge, and **data skew** (the classic senior interview topic)
- [ ] Caching and persistence — and when caching makes things *worse*
- [ ] Partitioning strategy, file sizes, the small-file problem
- [ ] Spark SQL and the Catalyst optimizer
- [ ] Reading a Spark UI and finding the slow stage
- [ ] Structured Streaming — micro-batch, checkpointing, output modes

**Which language?** PySpark is more common in jobs; Scala/Java Spark is faster and closer to the engine. Learn PySpark for employability, and use your JVM knowledge to understand what is actually happening underneath. Very few people have both.

> **You are done when…** you can take a Spark job that takes 40 minutes and make it take 6, and explain exactly what you changed and why.
