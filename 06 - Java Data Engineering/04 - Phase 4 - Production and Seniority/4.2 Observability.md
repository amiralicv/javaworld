## ✅ Checklist

- [ ] The three pillars — metrics, logs, traces
- [ ] **Prometheus** — metric types, PromQL, scraping, alert rules
- [ ] **Grafana** — dashboards people actually use, not decoration
- [ ] Structured logging and log aggregation (Loki / OpenSearch)
- [ ] Distributed tracing — OpenTelemetry
- [ ] **SLI / SLO / error budget** — how professionals define "is it working?"
- [ ] Alert design — alert on symptoms, not causes. **An alert that fires and nobody acts on is worse than no alert.**
- [ ] On-call, incident response, and blameless postmortems

> **You are done when…** you can answer "is the data platform healthy right now?" with a dashboard instead of an opinion.
