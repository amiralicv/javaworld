## ✅ Checklist

The interview skill and the actual job.

- [ ] Requirements gathering — volume, velocity, latency, freshness, retention, budget, who reads it
- [ ] **Batch vs streaming decision** — and the courage to choose batch when batch is right
- [ ] Storage layer choice — warehouse vs lakehouse vs OLTP replica
- [ ] Handling scale — partitioning, sharding, backpressure
- [ ] Failure modes — what breaks, what happens when it does, how it recovers by itself
- [ ] Cost modeling — storage vs compute vs engineer hours
- [ ] Multi-tenancy and isolation
- [ ] Migration strategy — how to change a live system without losing data or trust
- [ ] **Writing a design doc** — problem, options, trade-offs, decision, risks. This one artifact is what senior looks like on paper.

**Practice:** design one system per month on paper. *"Design the data platform for a ride-hailing app." "Design fraud detection ingestion for a bank." "Design a reporting warehouse for an e-commerce site with 5 million SKUs."* Write it. Then attack your own design.
