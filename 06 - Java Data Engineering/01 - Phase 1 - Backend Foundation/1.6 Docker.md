## ✅ Checklist

The bridge between "works on my machine" and "runs in production." Everything in Phase 3 arrives as a container.

- [ ] Images vs containers vs layers
- [ ] Writing a good `Dockerfile` — multi-stage builds, small base images, layer caching, non-root user
- [ ] Volumes and networks
- [ ] `docker compose` — run a multi-service stack locally (**this becomes your entire lab**)
- [ ] Environment variables and config injection
- [ ] Reading container logs, `exec` into a running container to debug

> **You are done when…** one `docker compose up` gives you app + Postgres + one more service, all talking to each other.
