## ✅ Checklist

Not "Java syntax." You have that. This is the layer under it.

- [ ] **Collections in depth** — when `ArrayList` vs `LinkedList` vs `HashMap` vs `TreeMap`, and *why*. Big-O of each operation.
- [ ] **Generics** — bounded types, wildcards, type erasure and what breaks because of it
- [ ] **Streams API** — map/filter/reduce/collect/groupingBy, lazy evaluation, when a plain loop is better
- [ ] **Optional** — used correctly, not as a null wrapper everywhere
- [ ] **Exceptions** — checked vs unchecked, never swallow, never `catch (Exception e) {}`
- [ ] **Concurrency** — threads, `ExecutorService`, `CompletableFuture`, race conditions, `synchronized` vs locks, why shared mutable state is the enemy
- [ ] **Virtual threads (Java 21+)** — what problem they solve, why the JVM suddenly matters again for high-throughput services
- [ ] **JVM basics** — heap vs stack, garbage collection (what a GC pause is), reading a stack trace like a detective
- [ ] **Build tools** — Maven and Gradle: dependencies, transitive conflicts, profiles, multi-module

**Read:** *Effective Java* (Bloch) — one item per day, not cover to cover. *Java Concurrency in Practice* — hard, but skim it once now and again in Phase 3.

> **You are done when…** you can explain to a junior why a specific `HashMap` usage caused a bug, and you can debug a thread-safety issue without guessing.
