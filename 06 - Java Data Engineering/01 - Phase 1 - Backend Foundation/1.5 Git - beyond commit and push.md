## ✅ Checklist

- [ ] Branching, merging, and **rebase** (know the difference and when each is safe)
- [ ] Merge conflicts without panic
- [ ] `git log`, `git diff`, `git blame`, `git bisect` (bisect will one day save you a whole day)
- [ ] `git stash`, `cherry-pick`, `reset` vs `revert` (know which one rewrites history)
- [ ] Pull request workflow, code review — giving *and* receiving
- [ ] Good commit messages — a subject line someone can read in a year

> **You are done when…** you have never once solved a Git problem by deleting the folder and cloning again.
