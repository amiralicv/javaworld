## ✅ Checklist

The thing that separates an engineer from a script writer. Data pipelines that are not tested are just expensive rumours.

- [ ] Unit tests — JUnit 5, AssertJ, Mockito
- [ ] Integration tests — **Testcontainers** (real Postgres in a container during tests; you will reuse this constantly in data work)
- [ ] Test structure — arrange/act/assert, one reason to fail per test
- [ ] What is *not* worth testing
- [ ] Static analysis and formatting in the build
- [ ] CI — a pipeline that builds, tests, and refuses to merge broken code

> **You are done when…** you refactor something scary and the test suite is the reason you are not afraid.
