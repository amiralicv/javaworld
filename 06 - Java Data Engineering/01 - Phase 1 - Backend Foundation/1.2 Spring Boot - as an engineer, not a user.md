## ✅ Checklist

- [ ] **Dependency injection** — what the container actually does, bean scopes, why constructor injection wins
- [ ] **REST APIs** — proper status codes, validation, error handling, pagination, idempotency
- [ ] **Spring Data JPA** — repositories, entity mapping, *and the N+1 query problem* (this one will follow you into data work)
- [ ] **Transactions** — `@Transactional`, propagation, isolation levels, what happens on rollback
- [ ] **Configuration & profiles** — externalized config, secrets never in code
- [ ] **Spring Security basics** — authentication vs authorization, JWT, why you never store a plain password
- [ ] **Actuator** — health, metrics, readiness. Your first taste of observability.
- [ ] **Async & scheduling** — `@Async`, `@Scheduled`, message listeners

> **You are done when…** you can build a service with auth, a database, validation, error handling and health checks from empty folder to running container **without a tutorial open.**
