## ✅ Checklist

You will live here for the rest of your career. In Iran especially, where you self-host everything, this is not optional. See [[06 - Java Data Engineering/06 - Iran Playbook|Iran Playbook]].

- [ ] Filesystem, permissions, users, `chmod`/`chown`
- [ ] Process management — `ps`, `top`/`htop`, `kill`, signals
- [ ] `grep`, `sed`, `awk`, `cut`, `sort`, `uniq`, `wc`, pipes and redirection
- [ ] `ssh`, `scp`, `rsync`, key-based auth
- [ ] `systemd` — write a unit file, start/stop/enable a service, read `journalctl`
- [ ] `cron` — and why it is not a scheduler for pipelines (you will replace it with Airflow in Phase 3)
- [ ] Networking basics — ports, `netstat`/`ss`, `curl`, DNS, what a reverse proxy does
- [ ] Bash scripting — variables, loops, conditionals, exit codes, `set -euo pipefail`
- [ ] Disk and memory — `df`, `du`, `free`, and how to find *why* a box is full at 3 AM

> **You are done when…** you can take a fresh Linux server and put your Spring Boot app on it, running under systemd, behind nginx, with logs you can read.
