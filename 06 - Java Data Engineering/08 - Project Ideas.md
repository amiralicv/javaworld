# 💡 Java / Spring Boot — Beyond Basic Backend

> Core idea: Java isn't the limitation. Project _type_ was. Backend CRUD is boring in every language.

## 1. Real-time / IoT

- [ ] Spring Boot + MQTT — control smart devices via Raspberry Pi
- [ ] Weather station: sensor → Java app → live dashboard (WebSocket)

## 2. Games

- [ ] LibGDX — Java game framework (Minecraft was built in Java)
- [ ] Multiplayer game backend with Spring Boot (matchmaking, leaderboard, live rooms via WebSocket)

## 3. Desktop Apps

- [ ] JavaFX — build a real GUI app (e.g. personal finance tracker with charts)

## 4. Real-time Systems

- [ ] Spring Boot + WebSocket + STOMP → live chat app
- [ ] Live stock price tracker
- [ ] Multiplayer quiz app (Kahoot clone)

## 5. Data / AI

- [ ] DL4J (Deeplearning4j) — ML inside the JVM
- [ ] Spring Boot as a wrapper calling a Python ML model via API

## 6. Automation / Bots

- [ ] Discord bot — JDA library
- [ ] Telegram bot with Spring Boot

## 7. Distributed Systems (Java's strongest zone)

- [ ] Microservices: order service + payment service + inventory service
- [ ] Kafka or RabbitMQ for inter-service messaging

---

**Rule:** Pick ONE. Finish it. Don't chase YouTube demos.
