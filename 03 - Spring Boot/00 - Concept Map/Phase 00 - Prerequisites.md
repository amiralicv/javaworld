## ✅ Checklist

- [ ] **1. JVM, JDK, JRE, classpath** 🔴 — what runs your code, and how Java finds classes at runtime.
- [ ] **2. Build tools (Maven / Gradle)** 🔴 — dependencies, build lifecycle, `pom.xml` / `build.gradle`, transitive dependencies.
- [ ] **3. Java annotations** 🔴 — what `@Something` actually is: metadata on code, readable at runtime.
- [ ] **4. Reflection & classloading (basic idea)** 🔴 — how a framework can create objects and call methods it never saw at compile time. This is the engine under Spring.
- [ ] **5. Interfaces & "program to an interface"** 🔴 — why depending on an interface instead of a concrete class makes swapping and testing possible.
- [ ] **6. Core design patterns** 🔴 — Singleton, Factory, Proxy, Template Method, Strategy, Observer, Decorator. Spring is these patterns wearing annotations.
- [ ] **7. Servlet, Servlet container, filter chain** 🔴 — the layer Spring MVC sits on top of.
- [ ] **8. HTTP fundamentals** 🔴 — methods, status codes, headers, body, content types, statelessness.
- [ ] **9. JSON & serialization** 🔴 — object ⇄ text, and why field names matter.
- [ ] **10. SQL & relational basics** 🔴 — tables, joins, indexes, transactions. Needed long before JPA.
